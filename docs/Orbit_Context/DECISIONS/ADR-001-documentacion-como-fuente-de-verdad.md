# ADR-001 — Documentación como fuente de verdad

## Decisión
La lógica de negocio de Orbit se documentará en archivos Markdown versionados dentro del repositorio.

## Motivo
La IA no debe depender de memoria conversacional para entender reglas críticas. La documentación debe ser explícita, mantenible y auditable.

## Consecuencia
Antes de desarrollar nuevas funcionalidades, Claude o cualquier desarrollador debe consultar la documentación vigente.
