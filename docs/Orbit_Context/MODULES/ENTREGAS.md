# Módulo Entregas

## Propósito
Controlar la entrega final de cenizas, recordatorios, plantas, reportes u otros elementos.

## Funciones mínimas
- Crear entrega.
- Programar fecha y responsable.
- Validar componentes listos.
- Registrar evidencia.
- Permitir entrega parcial.
- Cerrar entrega.

## Estados sugeridos
- Pendiente de programación.
- Programada.
- En ruta.
- Entregada parcial.
- Entregada completa.
- Novedad.
- Cerrada.
